# Wifi-password-security-monitor-Wi-Fi Password Security Auditor

The Wi-Fi Password Security Auditor is a Python-based application designed to evaluate the strength and security of Wi-Fi passwords. It checks password length, uppercase letters, lowercase letters, numbers, and special characters. It also identifies common password patterns and repeated characters that may reduce password security.

The program calculates a security score out of 7 and classifies the password as Weak, Moderate, Strong, or Very Strong. It provides security recommendations to help users create stronger passwords. The application uses Python's "re" module for pattern matching and the "getpass" module to accept passwords without displaying them in the terminal.

This project helps users understand basic password security practices and encourages the use of strong, unique passwords. It performs a password audit only and does not test the actual Wi-Fi network.
